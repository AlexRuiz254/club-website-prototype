# Example Club Website

Prototype multi-page sports club website built as a web development practice project.

## Overview

This project was created mainly to practice HTML structure and basic website organization.  
The goal was to design a simple multi-page website for a fictional sports club and experiment with page layout, navigation and content structure.

## Technologies

- HTML
- CSS
- Basic JavaScript

## Pages

- Home page
- Club presentation
- Organization chart
- Collaborators / sponsors

## Notes

This project was developed as a learning exercise focused primarily on practicing HTML and basic web page structure.  
Some information was anonymized and replaced with placeholder content for privacy reasons.
